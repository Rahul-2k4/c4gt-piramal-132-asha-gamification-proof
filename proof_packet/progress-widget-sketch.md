# Progress Widget Sketch

The first UI should be small and quiet. It should recognize work without interrupting health forms.

## Home/Profile Widget

```text
This week

Progress points: 140
Milestones: 2 unlocked
Pending sync: 3 events

[#######---] 70% toward weekly milestone

Recent recognition
- ANC follow-ups completed
- Child immunization visits updated
- NCD screening records submitted
```

## Milestone Detail

```text
Milestone unlocked

Consistent Follow-up
3 ANC follow-ups completed this week.

Why this matters:
Timely visits help mothers stay connected to care.

Sync status:
Saved on this device. Will sync when network is available.
```

## Copy Principles

- Use encouraging, non-competitive copy.
- Avoid ranking language such as "behind", "failed", "last", or "poor performer".
- Show pending sync clearly so offline work still feels counted.
- Use simple language that can translate well to Hindi and Assamese.
- Do not show beneficiary names in the gamification widget.

## Placement

Preferred first location: home/profile dashboard, near existing ASHA dashboard or incentive surfaces.

Avoid: modal popups after every form save. Field workers should not need to dismiss gamification UI during clinical workflows.
